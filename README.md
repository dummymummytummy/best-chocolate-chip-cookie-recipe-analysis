# Chocolate Chip Cookie Recipe Analysis

## Overview
This project analyzes 34 popular chocolate chip cookie recipes 
to identify which recipes meet the criteria for a crispy edge, 
chewy middle, and caramel flavor, and how those recipes compare 
in ratings to recipes that do not meet the criteria.

## Dataset
The dataset contains 34 recipes and 30 columns including 
ingredient amounts, baking techniques, computed ratios, 
criteria scores, and ratings.

## Tools Used
- Power BI (visualizations)
- Microsoft Excel (data review)

## Files
- Chocolate_Chip_Cookie_Dataset.csv — the full dataset
- FinalProject_PowerBI_Dhakal.pdf — Power BI visualizations
- FinalProject_Dhakal.pdf — project worksheet

## Key Findings
- Recipes meeting all 3 criteria averaged a 4.8 rating
- Brown butter recipes rated higher than regular butter recipes
- Top rated recipes used 60 to 85 percent brown sugar
- All recipes baked at 375°F met the crispy edge criteria
- Bon Appetit and Smitten Kitchen scored a perfect 3.0 criteria score
